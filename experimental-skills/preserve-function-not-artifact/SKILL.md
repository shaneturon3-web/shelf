# Preserve Function, Not Artifact

When changing an artifact, identify four things before editing:

1. the function or semantic payload that must survive;
2. the current carrier and its historical constraints;
3. the receiving carrier and its new constraints;
4. losses, substitutions, and unresolved equivalences.

Test the result against the original use, not its visual or verbal similarity.
Record the minimum payload, the changed surface, and whether the original
context still exists. A successful transfer can preserve function while
changing identity; it cannot claim identity merely because the new object works.

Failure condition: if repair replaces the authorial or operational payload,
preserves an obsolete container, or declares equivalence without testing the
receiving context, stop and record the mismatch.
