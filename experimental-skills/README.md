# Experimental Skills

These four skills are deliberately separate for activation tests. They are
not account plugins and are not installed into the global Codex skill path.

| Skill | Domain | Test status |
|---|---|---|
| `capture-before-organization` | global extraction | experimental |
| `preserve-function-not-artifact` | global transfer and repair | experimental |
| `route-contradiction-before-resolution` | TOM/editorial operation | experimental |
| `selection-as-irreversible-cut` | TOM/editorial operation | experimental |

Each `SKILL.md` is self-contained so activation can be tested independently.
Promotion requires behavioral evidence, overlap review, and rollback metadata.
