# Capture Before Organization

Use this skill during first-pass corpus discovery. It is a capture operator, not
a taxonomy or synthesis operator.

For each observation, record:

- source path, location, and authority;
- exact wording or a faithful bounded excerpt;
- neutral description before interpretation;
- uncertainty, contradiction, and negative space;
- direct relations and possible aliases;
- what would be lost if the observation were merged now.

Keep duplicates and competing labels until an independent comparison shows they
carry the same function. Do not promote a memorable term merely because it
recurs. The output is a provenance-bearing capture ledger and a short list of
candidate distinctions for the next pass.

Failure condition: if the first label, summary, or taxonomy makes a later
source distinction disappear, mark the capture as contaminated and recover from
the source rather than silently repairing the ledger.
